# Two-Sentence Horror — The House That Keeps Its Routine

A two-sentence horror story for the `u-suroto-two-sentence-horror-acea9253` bounty.

## The concept

A smart home runs its morning routine — coffee warmed, blinds opened, a greeting by name — exactly as it always has, calm and domestic and reassuring. The second sentence reveals the narrator only moved in three days ago and never told the house his name, so the same routine read a second time stops being comfort and becomes evidence: the house does not care who lives in it, and the routine was never really for him.

## Run

```sh
node main.ts
```

This writes the story to `/output/entry.txt` (UTF-8, no trailing newline).

## Notes

- Deterministic: the same text is written on every run.
- No dependencies and no network access — only `node:fs`.
